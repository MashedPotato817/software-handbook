# Codex / ChatGPT

Codex 是 OpenAI 提供的编程智能体，可以在项目中读取文件、运行命令和修改代码；ChatGPT 是通用的对话助手，适合问答、写作和资料整理。两者已经整合在同一个客户端中，安装一个软件即可使用。

## 教程

- [Windows 安装与首次使用](install.md)：下载客户端，通过 Microsoft Store 完成安装，并选择注册 ChatGPT 账号或使用 CC Switch 完成配置。
