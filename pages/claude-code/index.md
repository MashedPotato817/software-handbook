# Claude Code

Claude Code 是 Anthropic 的 AI 编程助手，可以阅读项目文件、解释代码和协助修改。本篇使用 Claude 桌面应用的 **Code** 标签完成入门。

> 适用环境：Windows 桌面端，按处理器选择 x64 或 ARM64 安装包。本文为待人工验证的草稿，实际软件版本待补。

## 1. 准备账号与练习文件

- 准备具有 Claude Code 使用权限的 Anthropic 账号。桌面版官方入门资料列出的方案为 Pro、Max、Team 或 Enterprise；能使用普通聊天不代表已有 Code 权限。
- 确认电脑能够访问官方下载和登录页面，具体服务可用地区以官方要求为准。
- 在桌面新建 `AI练习` 文件夹，用记事本在其中保存 `练习.txt`，内容写“这是我的第一个 AI 编程助手练习。”。

## 2. 下载并登录

1. 打开 [Claude Code 桌面版官方入门页](https://code.claude.com/docs/en/desktop-quickstart)，找到 Windows 下载入口；ARM64 电脑选择页面中的 ARM64 安装包。
2. 双击下载的安装包，按提示安装，再从开始菜单打开 **Claude**。
3. 按提示登录 Anthropic 账号，点击应用中的 **Code** 标签。
4. 如果提示升级套餐或没有使用权限，先确认账号权限，再继续操作。

桌面版已包含 Claude Code，本篇无需另装 Node.js 或终端版 CLI。

## 3. 选择练习文件夹

1. 在输入框下方的环境选择器中，选择 **Local** 分组中的本地环境。
2. 点击旁边的项目文件夹控件，选择 **Open folder…**，打开桌面的 `AI练习`。
3. 在模型选择器中选择账号可用的模型；首次练习将权限模式设为 **Manual**，逐项查看操作请求。

不同版本的控件位置可能变化；找不到环境选择器时，对照官方入门页中的旧版布局说明。

## 4. 首次对话并验证

在 Code 输入框发送：

```text
请只读取当前文件夹中的“练习.txt”，用一句话概括内容。不要修改文件，也不要安装或运行任何程序。
```

确认以下结果：

1. 回复对应刚才保存的文字，没有登录、额度或模型不可用的报错。
2. 用记事本重新打开 `练习.txt`，内容没有变化。

完成后可确认基本文件读取与对话可用。遇到问题时，记录报错、账号权限和软件版本。
