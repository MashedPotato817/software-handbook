# 嘉立创EDA

嘉立创EDA 用于绘制电子电路原理图和 PCB。本篇选用**专业版网页版**，先练习放置两个电阻、连接导线和保存工程。

> 适用环境：Windows 10/11，最新版 Chrome 或 Edge，联网并具有嘉立创EDA账号。本文为待人工验证的草稿；不涉及标准版或客户端安装。

## 1. 打开专业版并登录

1. 打开 [嘉立创EDA专业版在线编辑器](https://pro.lceda.cn/editor)，无需安装客户端。
2. 点击页面右上角的“注册”或“登录”，完成账号登录。
3. 确认进入专业版编辑器；本篇沿用默认设置，不更改快捷键或规则。

## 2. 新建练习工程

1. 在编辑器开始页点击“新建工程”，名称填写“电阻连接练习”，点击“保存”。
2. 在左侧工程内容中找到默认创建的板子和原理图，双击打开原理图图页。
3. 如果原理图下没有图页，在顶部菜单选择“新建 → 图页”；创建后双击图页打开。

工程会同时建立 PCB 等文件，本次只操作原理图。

## 3. 放置电阻并连线

1. 在左侧“常用库”中找到电阻，选择后在画布上单击放置两个；按 `Esc` 结束连续放置。
2. 单击选中电阻，在右侧属性面板查看位号与阻值，确认两个元件没有重叠。
3. 选择顶部菜单“放置 → 导线”。
4. 点击第一个电阻的一个引脚端点，再点击第二个电阻的一个引脚端点，右键结束绘制。
5. 确认导线连接在引脚端点上，没有只接到电阻图形的边缘。

这里只练习画图，不构成可工作的完整电路。

## 4. 保存并验证

1. 选择“文件 → 保存全部”，或按 `Ctrl+S`。
2. 关闭当前工程后，从左侧工程列表重新打开，确认两个电阻和导线仍保留。
