# DeepSeek Harness

DeepSeek Harness 是一款 AI 助手，可以帮你整理资料、处理文件和编写代码。本篇介绍 Windows 桌面版的安装与首次使用。

> 适用环境：Windows 64 位桌面端预览版。本文为待人工验证的草稿，具体软件版本待补；按钮名称可能随版本变化。

## 1. 下载

打开 [DeepSeek Harness 官方网站](https://www.deepseek.com/harness/)，选择 **Windows（64 位）**，下载安装包。

不确定电脑是否为 64 位时，可在 Windows 的“设置 → 系统 → 关于”中查看“系统类型”。

## 2. 安装并登录

1. 双击下载的安装包，按提示安装；安装位置可以保持默认。
2. 安装完成后，点击“立即启动”，或从开始菜单打开 DeepSeek Harness。
3. 按应用提示登录。如果跳转到浏览器，完成登录后允许浏览器打开 DeepSeek Harness，返回应用继续。

## 3. 完成首次设置

按照界面提示依次设置：

- **可用额度**：查看账号显示的可用额度和有效期，按页面提示完成必要设置。
- **使用用途**：按自己的需要选择，例如日常工作或编程。
- **工作过程展示**：按个人偏好选择。

完成后进入主界面。额度与赠送活动以账号页面显示为准。

## 4. 开始使用并验证

1. 查看当前工作区。工作区就是 AI 处理文件的文件夹；如果需要选择，先选一个用于练习的文件夹。
2. 新建对话，发送“请用一句话介绍你自己”。
3. 确认收到回复，没有登录、额度或模型不可用的报错。
4. 退出并重新打开应用，确认还能找到刚才的对话。

完成以上检查，即可确认基本对话能够使用。遇到问题时，记录报错内容和软件版本，方便进一步排查。
