# Origin

Origin 用于整理实验数据和绘制科学图表。本篇介绍 Windows 安装、许可准备，以及用官方样例画第一张折线图。

> 适用环境：Windows 10/11 64 位（x64），以官网当前安装包和帮助文档为参考。本文为待人工验证的草稿，实际安装版本待补。

## 1. 获取安装包和许可

1. 先查看学校或单位是否提供 Origin 授权；如有，向软件管理人员获取对应安装包、序列号与许可说明。
2. 没有现成授权时，打开 [Origin 官方试用页](https://www.originlab.com/try)，点击 **Download Free Trial**。
3. 在下载申请页如实选择使用经历和身份，完成官网要求的账号信息后下载安装包。

试用需要申请限时许可。具体期限以官网为准，不把试用当作长期授权。

## 2. 安装

1. 使用具有管理员权限的 Windows 账号，打开下载的安装包；解压后的安装程序为 `Setup.exe`。
2. 阅读并接受许可协议。试用选择 **Install Origin Trial**；持有正式序列号时选择 **Install Product (requires serial number)**，填写授权方提供的信息。
3. 安装目录、附加组件和开始菜单位置没有特别要求时保留默认值。
4. 核对安装摘要，继续安装，看到 **Setup Complete** 后点击 **Finish**。

## 3. 首次启动和许可

1. 从开始菜单打开 Origin；如果要求选择 **User Files Folder（用户文件夹）**，选择自己可以读写的本机文件夹，用于保存个人数据和设置。
2. 使用校方或单位许可时，按管理人员提供的许可类型完成激活；并发网络许可还需连接指定许可服务器，不自行填写地址。
3. 试用用户在 **Trial License Options** 中选择 **Get a free 21 day trial license now**，点击 **OK**。
4. 浏览器打开申请页后，点击 **Continue**，登录 OriginLab 账号，确认邮箱正确，再点击 **Get Trial License**。
5. 收到邮件后，将许可文本粘贴到 Origin 的第一个输入框，第二个输入框填写接收许可的邮箱，点击 **OK**。

看到许可更新成功并能进入工作表后，再继续练习。英文菜单用于对应官方帮助中的名称。

## 4. 画图并验证

1. 在 Origin 中选择 **Help → Open Folder → Samples Folder**，打开官方样例目录。
2. 进入 `Curve Fitting` 文件夹，将 `Sensor01.dat` 拖到 Origin 的空白工作表中；弹窗中选择 **Use Connector**，点击 **OK**。
3. 点击 **B 列的列标题**，选中整列；点击左下方 **2D Graphs** 工具栏中的 **Line（折线图）** 按钮。
4. 确认弹出图形窗口，能够看到样例数据的折线。
5. 选择 **File → Save Project**，保存项目；重新打开保存的项目，确认数据表和图形仍在。
