# draw.io

draw.io 用于绘制流程图、结构图和技术示意图。本篇用网页版画一张简单流程图，并保存到电脑。

> 适用环境：Windows 10/11，使用浏览器打开网页版。本文为待人工验证的草稿，界面名称可能随更新变化。

## 1. 打开网页版

1. 打开 [draw.io 在线编辑器](https://app.diagrams.net/)，本篇无需安装桌面客户端。
2. 如果出现存储位置选择，选择 **Device（设备）**，将文件保存在电脑上。
3. 如果出现 **Create New Diagram（创建新绘图）**，点击后输入文件名 `我的流程图.drawio`，选择 **Blank Diagram（空白绘图）**，点击 **Create（创建）**。
4. 如果直接进入空白画布，可以开始绘图，稍后再选择保存位置。

## 2. 画出两个步骤

1. 在左侧 **General（通用）** 图形库中，拖一个矩形到画布上。
2. 双击矩形，输入“准备资料”，按回车结束输入。
3. 再拖一个矩形到右侧，输入“完成整理”。
4. 将鼠标移到第一个矩形上，找到向右的方向箭头。
5. 从箭头处拖向第二个矩形，等第二个矩形边框变蓝后松开鼠标。

画布上应出现两个矩形，以及从“准备资料”指向“完成整理”的连接线。

## 3. 保存并验证

1. 点击 **File → Save as（文件 → 另存为）**。
2. 文件名填写 `我的流程图.drawio`，文件类型保留 `.drawio`，位置选择本机设备并保存。
3. 在电脑上找到保存的文件；浏览器若直接下载文件，查看“下载”文件夹。
4. 回到编辑器，选择 **File → Open From → Device（文件 → 从……打开 → 设备）**，选择刚保存的文件。
5. 确认两个矩形、文字和连接线均保留，且还能选中矩形修改文字。

若页面仍显示未保存的更改，先完成保存，再关闭标签页。
